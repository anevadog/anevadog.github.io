# CLAUDE.md

Este proyecto usa [`AGENTS.md`](AGENTS.md) como fuente principal de contexto, arquitectura, convenciones y reglas. Léelo antes de cualquier tarea y síguelo.

Al iniciar una sesión, lee también [`docs/memoria.md`](docs/memoria.md) para conocer el estado actual y el punto de continuación.

Recordatorio de las reglas críticas (detalle en `AGENTS.md` §9):

- Ninguna operación Git que modifique el repositorio sin consentimiento explícito para esa acción concreta.
- No instalar dependencias, desplegar ni usar servicios externos sin autorización.
- No avanzar de etapa (planificar → aprobar → implementar → validar → documentar) sin aprobación.
